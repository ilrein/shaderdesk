Your desktop,
as a shader.

Shaderdesk is a tiny, open-source macOS menu bar app that turns your wallpaper into live Metal shaders: boiling stars, a ray-traced black hole, synthwave and rainy neon cities. It uses a few milliseconds of GPU per frame and stops drawing when your desktop is covered.

Get it for macOS Star on GitHub

Scenes

Every clip is recorded straight from the app's Metal renderer. Click one to watch it bigger.

Native and light

Swift and Metal. It uses about 5% of one CPU core and a few ms of GPU per frame at full Retina resolution, and the app is under 1 MB.

No flicker

Each display gets one window at desktop level, on every Space. When the desktop is covered, drawing pauses and picks up again instantly.

One file per scene

A scene is a single .metal file, compiled at runtime. Save a file and the scene reloads live.

Private

Nothing leaves your machine. There's no telemetry, no account and no network access.

Install

Requires macOS 14 or later and the Swift toolchain (Xcode or the Command Line Tools). You don't need the Metal compiler, because shaders compile at runtime.

  1. Clone and build. The script builds the app, copies it to /Applications and launches it.
  2. Click the menu bar icon to open the picker. Click a scene to make it your wallpaper.
  3. Right-click the icon for Launch at Login and Quit. That's all the settings there are.
# build, install to /Applications and launch
git clone https://github.com/ilrein/shaderdesk
cd shaderdesk
scripts/build-app.sh --install

Make a scene

A scene is one fragment shader. Shaderdesk gives it the time, the display's layout, tiling noise, star helpers, HDR bloom and tone mapping.

  1. Drop a .metal file into ~/Library/Application Support/Shaderdesk/Scenes/. It shows up in the picker right away and reloads every time you save.
  2. Add a header with a title, a sort order, the bloom strength and tags for the picker's sidebar.
  3. Check it offline. Shaderdesk --snapshot out.png --scene id --bench 300 renders a frame and prints the GPU time.
//! title: Plasma
//! tags: Neon
//! bloom: 0.1

fragment float4 scene_frame(VOut in [[stage_in]],
                            constant Uniforms& U [[buffer(0)]],
                            constant Galaxy* G [[buffer(1)]],
                            constant Flare* F [[buffer(2)]],
                            texture2d<float> bg [[texture(0)]]) {
    float2 p = globalPoint(in.pos, U) / 400.0;
    float t = U.target.z;              // scene clock, seconds
    float v = sin(p.x + t * 0.2) + sin(p.y * 1.3 - t * 0.15);
    float3 col = 0.5 + 0.5 * cos(v + float3(0, 2, 4));
    return present(col * 0.2, in.pos.xy);
}

Send us a scene

Made something beautiful? Open a pull request and it can ship to everyone as a built-in scene. Anything goes: space, neon, nature, abstract. The bar is simple: it should look great on a 5K display, run in a few ms per frame and loop forever without a visible seam. The contributing guide has the details.
